## Searchable catalog of finance-specific agent skills.

Anyone can browse published skills. Logged-in users can favourite skills and create their own private skills, which they can submit for review; admin can approve or reject submissions (if approved, they will become available in the published skills section).

Each skill has:
- Short description for human audience (what the skill does, input, output)
- Step-by-step installation instructions (as a package from terminal line + as a SKILL.md file that can be uploaded to Claude/Codex/Cursor/etc.
